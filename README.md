## How to use
1. Download the latest release from the [releases page](https://github.com/ZeroDream-CN/asi-version-injector/releases).
2. Run the ResourceInjector.exe file.
3. Select the ASI plugin file (e.g. Menyoo.asi) that you want to inject.
4. Click the "Inject Build Config" button to inject the ASI plugin into the selected game build number.
5. Start the game and check if the ASI plugin is loaded.
